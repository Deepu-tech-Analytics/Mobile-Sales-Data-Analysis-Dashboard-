1.# Mobile-Sales-Data-Analysis-Dashboard – Power BI
2.📊 Project Overview
This project focuses on analyzing mobile phone sales data using Microsoft Power BI.
The dashboard provides an interactive view of sales performance, customer trends, transactions,     payment methods, and mobile brand performance. The goal of this project is to transform raw sales   data into meaningful insights through data cleaning, analysis, and visualization.
3.🎯 Project Objectives
Analyze overall mobile sales performance,Identify top-performing mobile brands and models,Analyze sales trends over time,Understand customer purchasing patterns,Analyze payment methods used by customers,Compare sales performance across different locations,Create an interactive and user-friendly Power BI dashboard.
4.🛠️ Tools & Technologies
Microsoft Power BI,Power Query,DAX,Data Cleaning & Transformation,Data Visualization,Microsoft Excel.
5.📈 Dashboard Features
Total Sales,Total Quantity Sold,Total Transactions,Average Sales,Sales by Mobile Brand,Sales by Mobile Model,Sales by Payment Method,Sales by City/Location,Monthly Sales Trends,filters and slicers.
6.🔄 Data Analysis Process
1. Imported the mobile sales dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Checked data types and handled data inconsistencies.
4. Created calculated measures using DAX where required.
5. Analyzed sales and customer-related information.
6. Created charts, cards, tables, and slicers.
7. Designed an interactive dashboard to present the findings.
7.🔍 Key Insights
- Identified the highest-selling mobile brands.
- Compared sales performance across different mobile models.
- Analyzed monthly sales trends.
- Identified commonly used payment methods.
- Compared sales performance across different locations.
- Examined customer purchasing patterns.
